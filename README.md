# Бюро — портфолио дизайн-студии

Концептуальный сайт независимой дизайн-студии: крупная типографика, лаймовые акценты и авторская графика проектов.

**[Посмотреть сайт](https://oppoupp.github.io/buro-portfolio/)**

- Адаптивная вёрстка для компьютеров и телефонов.
- Фильтрация работ и модальные окна с описанием проектов.
- Форма брифа со скачиванием текстового файла — без отправки данных на сервер.
- Поддержка клавиатурной навигации и уменьшенной анимации.

**Стек:** HTML, CSS и JavaScript без фреймворков. Графика создана средствами CSS; шрифт Manrope загружается из Google Fonts.

Для просмотра откройте `index.html` в браузере. Публикация — GitHub Pages, ветка `main`, папка `/ (root)`.

Учебный проект для портфолио. Студия, бренды и кейсы вымышлены.
